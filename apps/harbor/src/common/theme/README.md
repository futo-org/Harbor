# Atoms

`Atoms` are static Tailwind-like style objects built from the tokens
(`Spacing`, `BorderRadius`, `typography`, `ZIndex`, `Breakpoints`, `Opacity`).
Prefer them, or their tokens (e.g. `{ paddingTop: Spacing.sm }`), over
hard-coded numbers.

- Spacing: `p_*`, `px_*`, `py_*`, `pt_*`, `pb_*`, `pl_*`, `pr_*`, the same for
  margins (`m_*`, `mx_*`, ...), and `gap_*`, on the `Spacing` scale. Not every
  side has every step.
- Flex: `flex`, `flex_1`, `flex_row`, `flex_col`, `flex_wrap`, `flex_grow_*`,
  `flex_shrink_*`, `flex_basis_0`, `items_*`, `self_*`, `justify_*`.
- Position and size: `relative`, `absolute`, `fixed`, `sticky`, `inset_0`,
  `w_full`, `h_full`, `max_w_full`, `max_h_full`, `min_w_0`, `min_h_0`,
  `hidden`, `overflow_*`.
- Borders: `rounded_*` on the `BorderRadius` scale, and the 1px widths
  `border`, `border_t`, `border_b`, `border_l`, `border_r`, `border_x`,
  `border_y`, plus `border_0`.
- Text: `text_left`, `text_center`, `text_right`, `text_underline`.
- Other: `cursor_default`, `cursor_pointer`, `faded` and `faded_subtle` (on the
  `Opacity` scale), `outline_none` (removes the web focus ring).

For a layer filling its parent, use `StyleSheet.absoluteFill`.

# Theme

Colors come from `useTheme()`. Use `theme.atoms` (style objects) in style
arrays, or `theme.colors` (the same values as strings) for props that don't
take a style, such as `highlightColor` or an SVG `fill`. Don't import `palette`
in feature code. Hard-code a hex color only when it isn't a theme color, like
the platform brand colors in `features/verifications/utils/platforms.ts`.

Prefer writing styles with `createThemedStyles`: it builds a stylesheet once per theme
and returns a hook, and its entries can be arrays of atoms.

```tsx
const styles = useStyles();
return (
  <View style={styles.card}>
    <View style={styles.divider} />
  </View>
);

const useStyles = createThemedStyles((theme, define) =>
  define({
    card: [Atoms.p_md, Atoms.rounded_md, theme.atoms.box.raised.bg],
    divider: [theme.atoms.outline, Atoms.border_t],
  }),
);
```

Though when the styles are simple, like a few atoms or a conditional entry, they can
stay inline.

```tsx
const { theme } = useTheme();
return (
  <View style={[Atoms.p_md, Atoms.rounded_md, theme.atoms.box.raised.bg]}>
    <Text color="secondary">…</Text>
  </View>
);
```

## Text

Pass as `color` on `Text` and `Icon`.

- `primary`, `secondary`, `muted`: grays, from strongest to weakest.
- `accent`, `danger`, `success`, `warning`: hue colors.
- `light`, `dark`: white and black in both themes, for content on solid hue
  boxes and over media.

## Boxes

Every box has `bg`, `bg_hover` and `border`. A box's `border` edges that box or
separates parts of it. Border colors, here and in outlines, set only the color:
pair them with a border width atom.

- `primary`: the page and sheet background. Its `border` separates parts of the
  page: list rows, the top and tab bars, the web column edges, and cards on
  the page.
- `secondary`: a surface set apart from the page, like a menu, tooltip, key,
  segmented button, the active nav item, or a panel inside a sheet.
- `raised`: a translucent gray that shows on either of the above, for buttons,
  inputs, list groups, placeholders, and hovered or pressed menu rows.
- `accent`, `danger`, `success`, `warning`: solid hue fills, which take `light`
  content. They also have translucent `bg_subtle`, `bg_subtle_hover` and
  `border_subtle`, which take the hue's own text color.

## Outlines

For lines drawn over content rather than between parts of a box. Both are
translucent, so they show on any background.

- `outline`: cards embedded in a post or the composer (quotes, link previews),
  thread lines, dividers inside a `raised` panel, avatar rings, unfocused
  inputs.
- `outline_strong`: focused inputs, radio buttons.

## Other

- `backdrop.modal`, `backdrop.media`: dims behind modals and media viewers.
- `media_control.bg`: controls over images.
- `shadow.accent`, `shadow.neutral`
- `transparent.bg`, `transparent.border`

## Changing colors

`palette.ts` is generated by `pnpm --filter @polycentric/palette generate`
(`tools/palette`). `colors.ts` picks palette steps for each theme:
`SHARED_COLORS` holds what's the same in both, and `buildLightColors` and
`buildDarkColors` hold the rest.
