# Feeds

The Feed tab is your home timeline. It has three views you can swipe
between:

- **For you** shows recommended posts. Recommendations are computed by the
  servers you use, and each post is attributed to the server that suggested
  it, so no single server controls what you see.
- **Top** shows posts from people you follow, ranked.
- **Latest** shows posts from people you follow, newest first.

**Explore** shows what's happening across your servers with the same Top and
Latest views, plus a search bar. Explore and Search work without an account,
so you can browse before creating an identity.

The app remembers which view you were on. Re-tap the active tab to scroll
back to the top and refresh, or pull down to refresh on mobile.
