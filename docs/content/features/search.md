# Search

Search finds posts and people. Results come in three tabs: **Top** and
**Latest** for posts, and **People** for profiles, each with a follow
button.

While you type, a quick people lookup appears; submit the search to see the
full results. Search queries several servers, deduplicates what they
return, and attributes each result to the server it came from.

Search works without an account.
